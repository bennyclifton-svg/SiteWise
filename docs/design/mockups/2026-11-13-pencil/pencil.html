    How Pencil stays fast and honest
    
      
    SiteWise sells on speed and trust: a filing in a second, and a figure you can rely on. Most products bolt on a chat agent that loops through tools and can make up a number. Pencil makes a smaller promise and keeps it: one model call over facts SiteWise has already assembled, words only, every figure pinned to its record.
    
    
    

    
    
      
    Jev picks
    Reading, unchanged
    Files each document and reads profile evidence, invoices and proposals. Still the only AI that judges anything.
    
      
    Go computes
    Every figure
    Money, dates, counts, ranges and rule lookups, as today. In the background it also keeps one fact sheet per project for Pencil to write from.
    
      
    Haiku writes
    Words around the figures
    Answers, letters and catch-ups. It may write a figure only as a fact's tag, and SiteWise puts the value in. It has no tools and writes nothing to the project.

Filing, edits, navigation and typing stay exactly as fast as they are now: Pencil lives in its own package, and a test fails the build if filing ever imports it.

    Why Haiku cannot change a figure
    
        
      
          
    1. Go writes the fact sheet: each figure with a tag, its value, how it was decided and where it came from.
      2. 
          
    2. Haiku is told to write a figure only as its tag, like {f:cost.main.budget}. It is never asked to add, compare or convert.
      3. 
          
    3. SiteWise puts each value in from its own records, then reads the rest of the text. Any digit, amount, date or number word Haiku typed is highlighted. A draft cannot be inked until you keep or edit each one.
      4. 
        
    
        
    A tag that names no fact shows as an error. Unknown stays unknown: an unpriced line reaches Haiku as "unknown" and prints as unknown. Press Show what Haiku wrote on any answer to see the tags.
