## Checks and limitations

The complete prescribed local benchmark passes: 184 files over two rounds,
40 API samples, concurrency four, two background callers and 10% degradation.
Spec Home edit p50/p90 is **47.6/49.9 ms**, against **50/150 ms**. Filing passes
both rounds at **334.4/720.5** and **350.2/691.8 ms**, against **1000/2000 ms**.
All other local user-path gates pass. Automatic deterministic proposals are
included. No budget was relaxed; rejected experiments and failed runs are saved.
This uses recorded provider timing and does not establish target-VPS performance.

All Go packages, 29 browser cases, OCR, intake replay, strict knowledge checks,

on the final implementation. Source/Hale profile accuracy remains blocked below.
See [combined validation](../evidence/2026-10-07-m2-m3-validation.md) for exact
commands and limitations. Independent review found no further confirmed bounded
M2/M3 code omission. Knowledge remains draft.
