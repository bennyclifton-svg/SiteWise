# Shared RFP skeleton

Every discipline's RFP has these parts. Only sections 2, 3, 4 and 5 and the
discipline lines in R2-R5 change per discipline.

| Part | Shared? | Notes |
|---|---|---|
| 1 Project | shared table, plus discipline rows | Town planning adds site controls and pathway rows |
| 2 Your role | per discipline | |
| 3 Scope by stage | per discipline stage list; same table shape (stage, deliverable, shown when) | Stages are names only, no codes |
| 4 Allowances | same table shape; items per discipline | |
| 5 Scope position | same I / O / X table; items and the simple/complex rule per discipline | Architecture: class first. Town planning: pathway and risk |
| 6 Terms | shared, plus discipline lines | |
| 7 Evaluation | shared | |
| R1 Fee by stage | shared | Hourly stages are priced to the caps in section 4 |
| R2 Deliverables list | shared heading; content per discipline | Was "drawing list" for architecture |
| R3 Hourly rates | shared table; role list per discipline | |
| R4 Team | shared; accreditation line per discipline | DBP practitioner class, REAP |
| R5 Experience | shared; filter words per discipline | |
| R6-R9 | shared | R9 "reimbursables / disbursements" |

## Changes log

- 2026-10-09, town planning: R2 renamed "Deliverables list". Hourly stages
  get caps in section 4 and are priced lump sum to the cap, hourly beyond
  (all three planners priced post-lodgement hourly; Willowtree gave an
  allowance, which is comparable).
- 2026-10-09, town planning: the simple/complex rule is per discipline,
  not global.
- 2026-10-09, traffic: a stage can be priced as its own line inside R1
  when tenderers' costs depend on a count (survey locations). No change to
  the skeleton shape.
- 2026-10-09, traffic: quantities in the project table are the single
  source consultants price from (BG&E used a different GFA from everyone
  else).
- 2026-10-09, civil: R1 can be a stage x element grid when the
  discipline's work splits into priced elements (civil A-D). Taken from the
  2024 Yarramundi RFT; all four tenderers used it.
- 2026-10-09, civil: no provisional sums; every count-driven item is an
  allowance in section 4 (Enspire's provisional sums made its total look
  $28k cheaper).
- 2026-10-09, structural / civil: authority-asset work (Sydney Water SEA,
  rail) is its own stage, switched by a site flag, with a program note.
