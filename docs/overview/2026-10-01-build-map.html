Client guardrails

  • HTTP/2, warm connections, ~24 in flight, admission control
  • One 1.2 s deadline including queue wait; no hot-path retries
  • Circuit breaker; failures become grey, never block filing
  • Answers applied only if model, question IDs, type, options and probabilities match the pinned contract
  • Every call logs latency, tokens and confidence; recordings replay in tests

How to move it forward in priority order

Stop rules being confidently wrong

Fix or demote the title rule (16 wrong of 25 applied), and the revision, number and date misses. A rule should only settle what is unambiguous; everything else goes to Jev or stays blank.

Trust at a glance is the product. One wrong green costs more than ten blanks.

Fix candidate harvesting

Offer the bare sheet number alongside the fused form (S104 and S104-01), tag consultant job numbers so they are not offered as drawing numbers, and harvest full title-block titles.

Jev can only pick what code offers. This raises its ceiling the most.

Grow and review the answer keys

Get each field × option-shape to 30+ calibration answers, have the owner review Hale, Petersham and Newham keys, then re-run live and accept a baseline with -accept.

Without fitted thresholds, Jev is fast but switched off.

Close the three speed misses

Identity extraction (read fewer pages, bound PDFium work), document list (index and query shape: 143 ms → 50 ms), rules p90 tail. Then measure on the real VPS, not the dev box.

Whole intake already passes; components must too, or the build stays red.

Finish Task 12 and invite users

Health and speed endpoints, systemd + Caddy packaging, continuous Postgres and nightly file backups, a rehearsed restore. Then the first invite.

Real filings by real project managers are the best calibration data you can get.

Then widen the product

Search (FTS shortlist + Jev rerank, pick the faster shape on a gold set), OCR path for the 55 scans, verify the 9 missing NCC tables, and surface the fire pilot as a coordination view.

This is where the building model starts paying back.
