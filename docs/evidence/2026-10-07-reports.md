## What calls what

The store reads all report inputs in one transaction. One assembler emits
stable blocks for each template. RFT preserves package responsibilities,
retained systems, exclusions, latent-condition warnings and document identities.
PMP reads explicit delivery status, dates/variance, approvals, decisions and
cost coverage/forecast; uploads do not infer approval or progress. Dependencies
are saved finish-to-start records. Draft refresh protects user wording and
flags changed/removed sources. A new draft clones prior-issue edits once;
reset edits cannot silently reappear on later refreshes.

Issue locks the project, checks the draft version and changed-source consent,
refuses conflicted or unreviewed standard obligations, strips external budget
amounts unless disclosure is explicitly enabled, freezes references and a
canonical snapshot, renders a PDF and stores its content-addressed blob before
committing the issue. A failed transaction leaves at most an unreferenced blob;
no partial issue is visible. Later source changes do not rewrite the issue.
History downloads read only the frozen blob. Snapshot canonicalization preserves
exact decimal/integer representations across PostgreSQL JSONB key reordering.

## Renderer decision D-15 / D-16

Selected `github.com/signintech/gopdf v0.38.1`, using embedded Go fonts from
`golang.org/x/image v0.38.0`. This keeps the existing single Go binary and avoids
an external renderer process/service. It reuses a public PDF implementation
rather than adding a private PDF engine. Dependencies include gofpdi and
pkg/errors; x/sync and x/text versions move through the module graph. Sources:
[gopdf](https://github.com/signintech/gopdf),
[Go fonts](https://pkg.go.dev/golang.org/x/image/font/gofont).

A4, 15 mm margins, 10 pt body and 8.5 pt references. Unsupported font characters
return an error. Measurement and drawing use the same wrap logic. More than
two pages returns an overflow prompt; nothing shrinks or disappears. The
synthetic one-page PDF was extracted with pdfplumber and rendered with
pypdfium2; the image was visually inspected. Minimum extracted font 8.5 pt;
page 595×842 pt. Repeated rendering produces identical bytes. 40 renders measured
roughly 4.0/4.5 ms p50/p90 in the initial local spike (not target-host evidence).
The sample contains synthetic text, not Petersham source excerpts.
