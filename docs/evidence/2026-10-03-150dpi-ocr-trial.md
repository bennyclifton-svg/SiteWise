# Bankstown 150 DPI OCR trial

The owner authorised Tesseract OCR and the transfer of these five title-block
excerpts to TypeSafe. This is an opt-in local trial, not automatic OCR for new
uploads. Jev remains the classifier. Original PDFs are unchanged.

## Applied result

| Sheet | Title | Revision | Printed date |
|---|---|---|---|
| CC-01 | SITE SETOUT PLAN | D | 09/07/2015 |
| CC-02 | BASEMENT 2 | F | 09/07/2015 |
| CC-03 | BASEMENT 1 | F | 09/07/2015 |
| CC-04 | GROUND FLOOR PLAN | J | 14/07/2015 |
| CC-05 | LEVEL 1 | H | 07/09/2015 |

All five have kind `drawing` and lifecycle `design`. Only CC-04 passed the
existing discipline threshold for `consultant.architect`; the other four remain
blank. No thresholds were lowered. All recovered decisions are amber/review,
including deterministic parses. OCR spacing in numbers is retained (`CC- 01`).
CC-05's date is the literal printed September date, not a correction to July.

The five applied samples took 1222, 1292, 1236, 1388 and 1383 ms respectively,
including helper startup, PDF rendering, OCR, one Jev fan-out, audit writes and
database filing. Nearest-rank p50 was **1292 ms**, p90 **1388 ms**. The command
fails on p50 >1500 ms or p90 >2000 ms. Five samples on this Windows development
machine are a trial result, not a production latency guarantee. Upload time,
browser rendering and asynchronous full-text jobs are excluded.

## Implementation and checks

`tools/ocr_titleblock.py` renders the two previously inspected regions at 150
DPI and runs Tesseract 5.4.0, English tessdata_fast, OEM 1, PSM 6, one thread.
TSV word coordinates preserve the title-cell boundary and revision/date rows.
`internal/intake/ocr_trial.go` parses literal cells, excludes filename-derived
identity candidates, and reuses the existing Jev decision policy. Leading
border marks are excluded from the title substring; missing words are not
generated. The fixed template is intentionally specific to these A1 drawings.

The first dry run exposed filename titles and missing dates despite readable
OCR. Recorded cell fixtures now verify all four identity fields on all five
drawings. Integration coverage checks a single background Jev fan-out, amber
capping, cross-organisation isolation, repeated-commit rejection, atomic state
transition and preservation of concurrent user corrections. The intake and
store test suites pass against the separate test database.

The command requires an explicit manifest of 1–5 document IDs, organisation,
project, filename and original SHA-256. It also verifies the fast-model hash.
It accepts only single-page, matching-size, not-filed/no-text-layer documents.
`--apply` is opt-in; otherwise it writes proposals only. Existing user decisions
survive and OCR never establishes supersession. Full-page searchable OCR is
not provided by this title-block trial.

Python, Pillow and PDFium are trial-tool dependencies because native PDF
rasterisation and word-coordinate extraction are non-trivial. They are not
added to the Go web server or normal upload path. No server restart is required
for the database results; refresh the Bankstown register if needed.

Private before/evidence/decisions/after snapshots and timing results are in
`.tools/tesseract/trial-applied01/` (ignored). The recorded regression fixture
contains only drawing-control cells, with project/contact details removed.

## Reproduction

Build `./cmd/ocr-trial` and run from the repository root with
`SITEWISE_DATABASE_URL`, `SITEWISE_FILE_DIR`, and `SITEWISE_JEV_API_KEY` set.
Pass `--manifest <json> --python <executable> --tesseract <executable>
--tessdata <fast-model-directory> --output <new-audit-directory>`.
Manifest entries have `id`, `org_id`, `project_id`, `filename`, and `sha256`.
Only add `--apply` for explicitly selected documents. Already applied documents
are deliberately refused on a repeat run; do not reset their state to benchmark.

TypeSafe references: [pre-parsed extraction](https://docs.typesafe.ai/cookbooks/pre_parsed_value_extraction_cookbook),
[fan-out](https://docs.typesafe.ai/patterns/fan-out),
[confidence routing](https://docs.typesafe.ai/patterns/confidence-routing).
