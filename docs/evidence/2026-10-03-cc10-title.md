# CC-10 title parsing diagnosis

The reported Bankstown CC-10 retry recovered LEVEL 7 beside DRAWING NAME,
but saved a blank title. A read-only replay of the original PDF reproduced it.
The drawing-number cell was one OCR run, DwG.No. CC- 10. The existing OCR
identity parser handled CC- plus a separate numeric run, but not this inline
spaced form. It therefore failed to establish the complete number/revision
block required to prefer the printed title over the filename LEVEL 07 F.
Title selection went to Jev and remained blank under existing calibration.

The parser now accepts the same explicitly labelled prefix and digits within
one run or two adjacent runs. A nearby current revision remains necessary to
mark the number as its own block identity; another page cannot corroborate it.
No confidence threshold, OCR setting, provider call, dependency or saved field
was changed. Replaying the original now settles CC-10, LEVEL 7 and F; date
remains unresolved. OCR-derived values remain capped at amber by filing.

The reduced regression failed before the fix and passes after. The full
intake suite and existing fragmented/ambiguous-number tests pass. Candidate
harvesting p50/p90 3.457/3.696 ms (budget 5/10 ms), rules 0.218/0.468 ms
(budget 1/1 ms). Original-file OCR/harvest probes measured 3.785 seconds
before and 3.741 seconds after: individual diagnostics, not a whole-filing
speed gate. There is no additional processing pass.

This investigation changed source and tests only. The running application
and saved CC-10 document were not changed.

After explicit owner approval, deployed locally on 3 October at 21:14 Sydney time. The build endpoint confirmed current server/UI. Reprocessed only CC-10 through the authenticated missing-details endpoint (HTTP 202); API polling observed completion in 5.16 seconds. Saved title LEVEL 7 and number CC-10 are amber rule values. Existing nonempty fields and user corrections were compared before/after and preserved. Date and discipline remain blank. Private before/after records are in ignored .tools/.
