Selection (`gen.fragmentRows`, `internal/program/generate.go`):

- A fragment with `scope: project` is a process step (design, consent, tender, handover). It is added **once**
  when its `applies_when` is true, and added as a conditional row labelled `If <unknown term>: …` when the
  predicate is unknown. False skips it.
- Any other fragment follows work items. It is considered once per included, live work item whose system is
  the fragment's system or below it. The predicate is evaluated with **that one item** as the works, so
  `work_action` reads that item's action. `retain` items bring nothing; `remove` items select only fragments
  whose predicate names `remove`; `investigate` items select only fragments that name `investigate` and
  hold outright. True adds the rows; unknown adds them as conditional `If …` rows; false skips.
- `det: ncc_class` is the applied `det.ncc_class` (comma-separated, any part matches). **It is not derived
  from the subclass.** With no applied NCC class, every class-gated fragment on a matching item is unknown,
  so the 1a, 2, 7b, 9b and fit-out variants of the same activity are all added as `If …` rows.
- Blank `det.flood_hazard` and `det.bushfire_prone_land` are treated as false (`assumeHazardsNo`).
- With one activity per fragment and a work item title, the row is labelled with the work item's title,
  not the library label (`instantiate`).
