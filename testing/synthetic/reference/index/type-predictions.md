## Reading the predictions

- **Refurb, remediation and advisory start with no work items.** Until a document reading or the user adds
  scope, these types get baseline consultants only (none at all for remediation and advisory), no
  construction cost lines, no construction fragments and no scope-addition consultants.
- **Remediation has no skeleton and no fragment.** It always falls back to `sk.generic`; only class-neutral
  process fragments can attach.
- **Consultants without an RFP template** get the generic `tpl.rfp-capex` RFP.
- **Process fragments that need `det.ncc_class`** (concept design, tender, site establishment) are added as
  `If …` rows when the class is unknown. They exist only for 1a, 2, 7b, 9b and refurb fit-out (5, 6, 9b), so a
  new or extended building of class 3, 5, 6, 7a, 8, 9a or 9c gets none (see program-fragments.md).
